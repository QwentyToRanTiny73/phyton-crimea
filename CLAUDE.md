# Правила работы Claude Code в этом репозитории

## Делегирование субагентам
- Поиск по коду отдавай `Explore`, разбор длинных логов и вывода сборки — `log-reader`, запуск тестов, линтера и сборки — `test-runner`. Все три работают на Haiku и не правят файлы (`.claude/agents/`).
- Дела в 1–3 вызова инструментов (известный файл, один grep, короткая команда) делай сам: запуск субагента дороже.
- Правки, решения и ревью делай сам, не через субагентов.
- Вывод субагента перед правкой проверяй по указанному месту: открой `путь:строка` и убедись, что там то, что описано.

## Если не выходит
1. Сначала проверь себя тестами (`test-runner`).
2. Потом предложи пользователю поднять effort на один уровень (`/effort`).
3. И только потом предложи модель сильнее (`/model`).
- Перед сменой модели делай `/compact` (или напомни о нём пользователю): у каждой модели свой кэш, и новая модель перечитывает всю историю без кэша, а после `/compact` история короче.
