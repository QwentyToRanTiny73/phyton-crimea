# Подключение домена с Ru-Center к Vercel

## Общая схема

```
Ru-Center (nic.ru)          Vercel
   DNS-записи          →    Ваш Next.js сайт
   домен.ру            →    phyton-crimea.vercel.app
```

Вы управляете DNS-записями на Ru-Center. Vercel будет принимать трафик по этому домену и автоматически выпустит SSL-сертификат (Let's Encrypt).

---

## Шаг 1. Добавить домен в Vercel

1. Откройте [vercel.com](https://vercel.com) → ваш проект
2. **Settings → Domains → Add**
3. Введите ваш домен, например: `phytoncrimea.ru`
4. Также добавьте `www.phytoncrimea.ru`
5. Vercel покажет DNS-записи, которые нужно прописать — **запишите их**

Vercel выдаст примерно следующее:
```
Type    Name    Value
A       @       76.76.21.21
CNAME   www     cname.vercel-dns.com
```

---

## Шаг 2. Прописать записи в Ru-Center

### Где это делается:
1. Войдите на [nic.ru](https://www.nic.ru) → **Личный кабинет**
2. Слева: **Услуги → DNS-хостинг** (или **Мои домены → ваш домен → DNS**)
3. Нажмите **Редактировать зону**

### Что прописать:

#### Для корневого домена (phytoncrimea.ru):
| Тип | Имя | Значение | TTL |
|-----|-----|----------|-----|
| `A` | `@` или пусто | `76.76.21.21` | `3600` |

> **Альтернатива**: Если Ru-Center поддерживает ALIAS/ANAME, можно использовать:
> `ALIAS @ cname.vercel-dns.com` — это лучше для apex-домена

#### Для www:
| Тип | Имя | Значение | TTL |
|-----|-----|----------|-----|
| `CNAME` | `www` | `cname.vercel-dns.com` | `3600` |

> **ВАЖНО**: Точные значения (`76.76.21.21` и `cname.vercel-dns.com`) берите из
> вашей панели Vercel — они могут отличаться в зависимости от региона/плана.

### Если уже есть A-записи для PrestaShop:
- Удалите старые A-записи для `@` и `www`
- Добавьте новые (из Vercel)
- Старый сайт перестанет быть доступен после обновления DNS

### Рекомендация перед переключением:
Сделайте скриншоты текущих DNS-записей PrestaShop — вдруг понадобится откатиться.

---

## Шаг 3. Дождаться применения DNS

DNS обновляется **от 15 минут до 24 часов** (обычно 1–2 часа в России).

Проверить статус можно на:
- [dnschecker.org](https://dnschecker.org) — введите ваш домен, проверьте тип A
- [whatsmydns.net](https://www.whatsmydns.net) — глобальная проверка

Когда DNS применится, Vercel автоматически:
- Обнаружит что домен указывает на него
- Выпустит SSL-сертификат Let's Encrypt
- Включит HTTPS

---

## Шаг 4. Проверить в Vercel

1. Vercel → Settings → Domains
2. Статус домена должен стать: **✓ Valid Configuration**
3. Откройте `https://phytoncrimea.ru` — должен открыться ваш новый сайт

---

## Настройка редиректа www → без www (или наоборот)

В Vercel → Settings → Domains укажите **Primary Domain**:
- `phytoncrimea.ru` (без www) — рекомендуется
- Vercel автоматически редиректит `www.phytoncrimea.ru` → `phytoncrimea.ru`

---

## Почта (@phytoncrimea.ru)

Если у вас настроена корпоративная почта через Ru-Center (MX-записи),
переключение A-записей **не затронет почту** — MX-записи останутся прежними.

Убедитесь что при редактировании DNS вы **не удалили** MX-записи вашего домена.

Пример сохранения почтовых записей:
```
MX    @    mail.nic.ru    10    (не трогать!)
TXT   @    v=spf1 ...         (не трогать!)
```

---

## Если используете NS-серверы Ru-Center

Стандартные NS для Ru-Center:
```
ns3.nic.ru
ns4.nic.ru
ns8.nic.ru
```

Если ваш домен делегирован на другие NS (например, Cloudflare, Яндекс), 
то DNS-записи нужно менять там, а не в Ru-Center.

Проверить NS можно командой:
```bash
nslookup -type=NS phytoncrimea.ru
```

## Схема работы после подключения

```
Пользователь → phytoncrimea.ru
                     ↓
               Ru-Center DNS
               (A → 76.76.21.21)
                     ↓
               Vercel Edge Network
               (CDN, SSL, гео-роутинг)
                     ↓
               Next.js приложение
               (сборка из GitHub)
```

## Быстрая проверка через терминал

```bash
# Проверить A-запись
nslookup phytoncrimea.ru

# Проверить www
nslookup www.phytoncrimea.ru

# Проверить SSL
curl -I https://phytoncrimea.ru
```

## Частые проблемы

| Проблема | Причина | Решение |
|----------|---------|---------|
| Домен не открывается | DNS ещё не обновился | Подождите 1–2 часа |
| Нет HTTPS (замок) | SSL ещё не выпущен | Vercel выпускает автоматически, до 10 минут после DNS |
| Ошибка 404 в Vercel | Домен добавлен, но нет деплоя | Убедитесь что в Vercel есть успешный деплой |
| Vercel пишет «Invalid» | Неправильное значение CNAME/A | Скопируйте точные значения из панели Vercel |
| Старый сайт открывается | DNS закешировался | Очистите DNS-кеш (`ipconfig /flushdns` на Windows) |
